# 파이프라인 설계와 구현 상태

## 기술 구현

TOML 설정 → 콘텐츠 큐 → JSON 검증 → 장면별 스웨덴어 TTS → 타이밍 검사·무음 패딩
→ 1080×1920 / 30fps / H.264 + AAC 렌더링 → ffprobe 규격 검사
→ SQLite 날짜·콘텐츠 실행권 획득 → OAuth 채널 확인 → 비공개 업로드 → 결과 기록.
OAuth 사전 검사는 생성·실행권 획득 전에 수행합니다. 업로드 전 영상 SHA-256을 확인합니다.
템플릿 배경과 자막을 사용하며, 영상 자료 자동 수집이나 생성형 이미지 생성은 구현하지 않았습니다.

음성 모듈은 현재 eSpeak NG만 지원합니다. 비용·계정 설정 없이 스웨덴어를 생성하지만
자연스러운 말투를 위해 후속 단계에서 다른 TTS 공급자를 연결할 수 있습니다.
FFmpeg와 TTS 호출은 셸을 거치지 않습니다. 음성을 잘라내거나 테스트 검증을 우회하지 않습니다.
로컬 매니페스트는 작업 기록이며 보안 서명은 아닙니다.

## 내용 구현

사용자 선택은 스웨덴어 세계 상식입니다. 초기 대본은 금성의 회전, 달의 같은 면, 지구의 물입니다.
원문 출처와 대본을 함께 보관하고 사전 사실 검수 후 `approved`로 표시합니다.
초기 초안의 출처는 NASA이며 네트워크 접근과 원문 대조는 운영 전 별도 확인해야 합니다.
시청자 대상은 일반 상식 독자로 설정했습니다. 아동 전용 콘텐츠를 만들 경우 YouTube의
made-for-kids 설정을 별도로 검토해야 하며 현재 업로드 코드는 false를 명시합니다.

자막과 음성 문장은 필요하면 분리합니다. 훅 → 사실 → 오해 방지 맥락 → 마무리 구조를 사용합니다.
저작권이 불명확한 외부 영상·음악을 자동 삽입하지 않습니다.
큐 자동 보충, 출처 자동 수집, 생성형 AI 대본 작성은 구현되지 않았습니다.
이 기능을 추가할 때에도 원문 대조와 공개 전 검토를 유지해야 합니다.

## 설명과 설정

사용자 선택은 **Europe/Stockholm 오전 9시 이후 제작·비공개 업로드, 검토 후 공개**입니다.
TOML은 콘텐츠 큐, TTS 설정, 시간대, 실행 시각, 출력·상태 경로, 비공개 정책을 보관합니다.
워커가 5분 간격으로 확인하므로 업로드 시작 시각은 최대 약 5분 늦을 수 있습니다.
실행에 필요한 비밀값은 설정 파일에 넣지 않습니다. OAuth는 사용자 PC에서 수행합니다.
공개는 기존 업로드를 YouTube Studio에서 전환하며 API 자동 공개는 일일 실행기에 없습니다.

## 검증과 남은 단계

로컬 테스트는 실제 음성·영상 생성과 날짜·콘텐츠 중복 방지, 여름·겨울 시간 계산,
인증 실패·업로드 실패 후 상태 처리를 검증합니다. Google API 업로드는 모의 테스트입니다.
실제 OAuth 연결, 실제 비공개 업로드, YouTube 재생 검증은 아직 수행되지 않았습니다.
프로세스 지속 운영과 자동 재시작은 외부 감독자가 필요합니다.
로그인 도우미는 사용자 PC의 의존성 준비, 브라우저 OAuth, 채널 확인, 인증 파일 저장을 구현했습니다.
클라우드 환경 값의 입력은 아직 수동이며 도우미가 생성한 private 파일을 기준으로 입력합니다.
다음 단계는 실제 계정 동의, 콘텐츠 초안 검수, 첫 실제 비공개 업로드, 자연스러운 음성 공급자 선택입니다.
